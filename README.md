# היומן של סימה

אפליקציה אישית לניהול יומן, תזכורות והכנסות. עובדת באייפון מ"מסך הבית", בלי שרת ובלי הרשמה. כל הנתונים נשמרים רק בטלפון, וגם בלי אינטרנט.

## כתובת האפליקציה

**https://idochen88.github.io/sima-calendar/**

האתר מתארח ב-GitHub Pages מהמאגר https://github.com/idochen88/sima-calendar. כל שינוי שנשלח (push) לענף `main` מתעדכן באתר אוטומטית תוך דקה-שתיים.

## התקנה באייפון
1. פותחים את הכתובת ב-**Safari** (לא בכרום).
2. לוחצים על כפתור השיתוף (ריבוע עם חץ למעלה).
3. גוללים ובוחרים **"הוספה למסך הבית"**, ואז **"הוסף"**.
4. מעכשיו פותחים את האפליקציה רק מהאייקון במסך הבית.

## ייבוא אנשי קשר מהטלפון
1. באפליקציית **אנשי קשר**: לוחצים על "רשימות" למעלה, ואז לחיצה ארוכה על "כל אנשי הקשר" ← "ייצוא" ← "שמירה בקבצים".
2. ביומן: הגדרות ← "ייבוא אנשי קשר" ← בוחרים את הקובץ.
3. מעכשיו, כשמקלידים שם בטיפול חדש, מופיעים גם אנשי הקשר והטלפון מתמלא לבד. אפשר לייבא שוב מדי פעם כדי לעדכן.

## התראה לפני טיפול
אפליקציה מ-Safari לא יכולה לשלוח התראה בעצמה כשהיא סגורה, אז הטיפול נוסף ליומן של האייפון עם התראה (15 דקות לפני, ניתן לשינוי בהגדרות). אחרי שמירת טיפול חדש מופיעה שאלה "להוסיף ליומן האייפון?", ובכל כרטיס יש כפתור "התראה". אם מעבירים או מבטלים טיפול, צריך למחוק את המועד הישן ביומן של האייפון.

## כרטיס לקוחה ותמונות לפני/אחרי
בלשונית "לקוחות" לוחצים על לקוחה ונפתח העמוד שלה: טלפון, וואטסאפ, היסטוריית טיפולים ותמונות. "הוספת תמונות" מאפשר לצלם או לבחור מהגלריה. כל תמונה נשמרת עם תאריך ההעלאה (אפשר לתקן אותו בלחיצה על התמונה). למעלה מוצגת השוואה בין הישנה ("לפני") לחדשה ("אחרי"), ואפשר לבחור אחרות ולשלוח את ההשוואה כתמונה אחת. התמונות נכללות בגיבוי.

## הצהרות בריאות
בלשונית "הצהרות" יש קישור לכל טופס (כרגע: אנמנזה הסרות שיער). שולחים אותו בוואטסאפ, או מכרטיס הלקוחה ישר לצ'אט שלה. הלקוחה ממלאת, חותמת באצבע ושולחת. ההצהרה מגיעה לאפליקציה לבד ומשויכת ללקוחה לפי מספר הטלפון (אם אין התאמה, אפשר לשייך ידנית). בכרטיס הלקוחה רואים מתי נחתמה ההצהרה, והתראה אם עברה יותר משנה.

### הגדרה חד-פעמית של Firebase (השירות של גוגל שמעביר את ההצהרות)
1. נכנסים ל-https://console.firebase.google.com עם חשבון הגוגל ← **Create a project** ← שם: `sima-calendar` ← אפשר לכבות את Google Analytics.
2. בתפריט: **Build ← Firestore Database ← Create database** ← מיקום `eur3 (europe-west)` ← **Start in production mode**.
3. בתפריט: **Build ← Authentication ← Get started ← Email/Password** ← להפעיל (Enable) ← Save.
4. באותו מסך: לשונית **Users ← Add user** ← האימייל של סימה וסיסמה חדשה. מעתיקים את ה-**User UID** שמופיע בטבלה.
5. **Firestore Database ← Rules**: מדביקים את התוכן של הקובץ `firestore.rules`, מחליפים את `OWNER_UID` ב-UID מסעיף 4 ← **Publish**.
6. גלגל השיניים ליד Project Overview ← **Project settings** ← למטה **Your apps** ← סמל `</>` ← שם: `sima` ← Register. מעתיקים את `apiKey` ואת `projectId` לקובץ `js/cloud.js` (בתוך `CONFIG`).
7. באפליקציה, בלשונית "הצהרות": מתחברים פעם אחת עם האימייל והסיסמה מסעיף 4.

ההצהרות נמחקות מהענן מיד אחרי שהן עוברות לטלפון, ונשמרות בטלפון ובגיבוי.

### הטפסים הקיימים
| טופס | קישור |
|---|---|
| אנמנזה הסרות שיער | `form.html?f=hair` |
| אנמנזה טיפולי פנים | `form.html?f=face` |
| אנמנזה איפור קבוע | `form.html?f=pm` |

### הוספת טופס חדש
הטפסים מוגדרים בקובץ `js/forms.js`. כל טופס: מזהה (`id`), שם, שדות אישיים (`personal`), נושאים (`sections`) עם שאלות מסוג כן/לא (`yn`), תיבות סימון (`check`) או טקסט חופשי (`text`), הסכמות (`agreements`), ואפשרות להסכמות רשות (`options`). הטופס מופיע אוטומטית בלשונית "הצהרות". בדיקת תקינות: `node --test tests/*.test.js`.

## חשוב לדעת
- **גיבוי**: בהגדרות (גלגל השיניים) לוחצים "ייצוא גיבוי" ושומרים ב"קבצים" / iCloud Drive, או שולחים לעצמך בוואטסאפ. מומלץ פעם בשבוע-שבועיים.
- הנתונים קשורים לכתובת האתר. אם מחליפים כתובת, צריך לייצא גיבוי מהישנה ולייבא בחדשה.
- הנתונים באייקון של מסך הבית נפרדים מהנתונים בלשונית רגילה של Safari.
- **עדכון גרסה**: אחרי push לגיטהאב, באייפון סוגרים ופותחים את האפליקציה פעמיים.

## למפתחים
- `index.html`, `css/styles.css`, `js/app.js` (ממשק), `js/logic.js` (חישובים), `js/db.js` (IndexedDB), `sw.js` (אופליין)
- `form.html` + `js/form.js` (הטופס ללקוחה), `js/forms.js` (תוכן הטפסים), `js/cloud.js` (Firebase), `firestore.rules`
- בדיקות החישובים: `node --test tests/*.test.js`
- הרצה מקומית: `node tools/serve.js` → http://localhost:8765 (ה-service worker כבוי ב-localhost, אלא אם מוסיפים `?sw=1`)
- יצירת אייקונים מחדש: `python3 tools/make_icons.py`
