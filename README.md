# היומן של סימה

אפליקציה אישית לניהול יומן, תזכורות והכנסות. עובדת באייפון מ"מסך הבית", בלי שרת ובלי הרשמה. כל הנתונים נשמרים רק בטלפון, וגם בלי אינטרנט.

## כתובת האפליקציה

**https://idochen88.github.io/sima-calendar/**

האתר מתארח ב-GitHub Pages מהמאגר https://github.com/idochen88/sima-calendar. כל שינוי שנשלח (push) לענף `main` מתעדכן באתר אוטומטית תוך דקה-שתיים.

## התקנה באייפון
1. פותחים את הכתובת ב-**Safari** (לא בכרום).
2. לוחצים על כפתור השיתוף (ריבוע עם חץ למעלה).
3. גוללים ובוחרים **"הוספה למסך הבית"**, ואז **"הוסף"**.
4. מעכשיו פותחים את האפליקציה רק מהאייקון במסך הבית.

## ייבוא אנשי קשר מהטלפון
1. באפליקציית **אנשי קשר**: לוחצים על "רשימות" למעלה, ואז לחיצה ארוכה על "כל אנשי הקשר" ← "ייצוא" ← "שמירה בקבצים".
2. ביומן: הגדרות ← "ייבוא אנשי קשר" ← בוחרים את הקובץ.
3. מעכשיו, כשמקלידים שם בטיפול חדש, מופיעים גם אנשי הקשר והטלפון מתמלא לבד. אפשר לייבא שוב מדי פעם כדי לעדכן.

## התראה לפני טיפול
אפליקציה מ-Safari לא יכולה לשלוח התראה בעצמה כשהיא סגורה, אז הטיפול נוסף ליומן של האייפון עם התראה (15 דקות לפני, ניתן לשינוי בהגדרות). אחרי שמירת טיפול חדש מופיעה שאלה "להוסיף ליומן האייפון?", ובכל כרטיס יש כפתור "התראה". אם מעבירים או מבטלים טיפול, צריך למחוק את המועד הישן ביומן של האייפון.

## חשוב לדעת
- **גיבוי**: בהגדרות (גלגל השיניים) לוחצים "ייצוא גיבוי" ושומרים ב"קבצים" / iCloud Drive, או שולחים לעצמך בוואטסאפ. מומלץ פעם בשבוע-שבועיים.
- הנתונים קשורים לכתובת האתר. אם מחליפים כתובת, צריך לייצא גיבוי מהישנה ולייבא בחדשה.
- הנתונים באייקון של מסך הבית נפרדים מהנתונים בלשונית רגילה של Safari.
- **עדכון גרסה**: אחרי push לגיטהאב, באייפון סוגרים ופותחים את האפליקציה פעמיים.

## למפתחים
- `index.html`, `css/styles.css`, `js/app.js` (ממשק), `js/logic.js` (חישובים), `js/db.js` (IndexedDB), `sw.js` (אופליין)
- בדיקות החישובים: `node --test tests/*.test.js`
- הרצה מקומית: `node tools/serve.js` → http://localhost:8765 (ה-service worker כבוי ב-localhost, אלא אם מוסיפים `?sw=1`)
- יצירת אייקונים מחדש: `python3 tools/make_icons.py`
